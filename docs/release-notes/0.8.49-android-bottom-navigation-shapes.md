# HikeJournal Android 0.8.49 — Bottom navigation shapes (build 193)

**Release scope: Android only.** This release refines the bottom navigation to
match the designer's Hikes and Species references. Navigation destinations and
actions are unchanged.

## Android

- Hikes uses a fully rounded 80 dp navigation capsule beside an 80 dp circular
  orange add button. The add action remains the same, and its default shadow is
  removed to match the flat artwork.
- Species, Review, Map, and Publish use a square-corner, full-width green
  navigation bar. This removes the previous top-only rounding, including the
  partial-corner appearance on Map.
- Android `versionName` remains **0.8.49**. `versionCode` is **193**, incremented
  from **192** for this distributed build. `VERSION` was not changed.
- No functional changes.

## iOS

- **No functional changes.** No iOS source, version, build number, archive, or
  App Store artifact changed.

## Web

- **No functional changes.** Website source and Bluehost deployment were not
  changed.

## API
