# HikeJournal Android 0.8.49 — Brand redesign (build 190)

**Release scope:** Android + Web + API public pages. This is a visual-only
release. App behavior, data, service contracts, and account actions are
unchanged.

## Android

- Applied the supplied HikeJournal logo, tab icons, forest pattern, palette,
  and bundled Cormorant Garamond / Source Sans 3 typography across the Android
  app.
- Restyled Hikes, Field Guide, Species Review, Publish, Map, Trail Medals,
  tracking, onboarding, and the existing photo, species, journal, and route
  detail surfaces while retaining their current callbacks and data flow.
- Kept the five primary destinations visible: Hikes, Species, Review, Publish,
  and Map. Publish remains a first-class tab.
- Kept the GPS-safe phone-original media browser wired into journal uploads.
- Android `versionName` remains **0.8.49**. `versionCode` is **190**, incremented
  from **189** for this distributed Android build. `VERSION` was not changed.

## Web and API

- Restyled the HikeJournal public site with the supplied horizontal logo, brand
  colors, pattern, matching fonts, and exported Hikes / Field Guide visuals.
- Restyled the privacy, support, and account-deletion pages with the same
  visual system. Privacy and support copy is unchanged; the Google sign-in,
  account verification, and account-deletion flow are unchanged.
- No API route, response, data, authentication, or publishing behavior changed.
- **Bluehost deployment:** the static upload package is prepared. Its upload is
  waiting for the site owner's Bluehost sign-in; the public upload will be
  verified before this release is marked complete.

## iOS

- **No functional changes.** No iOS source, version, build number, archive, or
  App Store artifact changed. The reusable palette, assets, and native iOS
  redesign guidance are in [`docs/IOS_REDESIGN_HANDOFF.md`](../IOS_REDESIGN_HANDOFF.md).
