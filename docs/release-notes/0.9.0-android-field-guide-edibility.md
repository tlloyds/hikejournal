# HikeJournal 0.9.0 · Field Guide redesign

Android build 205. GitHub release tag `android-v0.9.0-field-guide-edibility`.

## Android

- Species detail now leads with the species identity and a prominent food-use indicator. **Toxicity concern** takes priority when a warning is documented. **Edible use documented** identifies plants with food-use evidence.
- Documented parts, warnings, and evidence limits are visible in the main entry. Full citations and attribution expand on demand, with natural history and field records underneath.
- The Field Guide index uses the same indicators. The private photo reference uses the new layout, and photo indicators remain opt-in.
- Android `versionCode` advances from **204** to **205**. The shared `VERSION` and Android `versionName` are **0.9.0**.
