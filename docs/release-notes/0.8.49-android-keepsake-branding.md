# HikeJournal 0.8.49 — Trail Keepsake branding

Scope: **Android only**.

## Android

- Update the Trail Keepsake image generated by a hike's Share action to use
  the same green-outline, white-bar mark and one-line **HikeJournal** wordmark
  as the Hikes page.
- Use the bundled static Quicksand faces: bold branding, medium labels,
  semibold distance/time values, and regular date/footer text. Use the regular
  Cormorant Garamond display face for a calmer, smaller hike title.
- Replace the older drawn contour treatment with the supplied green brand
  texture and a subtle darkening toward the footer. Match the place label to
  the app's orange accent and fit long place names with an ellipsis.
- Apply this design to the actual exported image and in-app previews through
  the same renderer. Preserve satellite imagery, route overlay/endpoints,
  map attribution, hike date/distance/time, selected-photo order, keepsake
  placement options, and photo limits. The GPS-safe original-photo picker and
  publishing paths are unchanged.
- Android version name remains **0.8.49**. Increment `versionCode` from
  **199** to **200**. Shared `VERSION` stays unchanged.
- Platform-qualified tag: `android-v0.8.49-keepsake-branding`.

## Debug-log triage

initially had a return-type initialization issue; it was corrected before the
successful render, and the local runner was removed from the production tree.
The 59 existing lint warnings and 1 hint remain. The SDK 26–27 signature check
retains its expected warning about the newer signature scheme. No production
logging was added. Previews use a synthetic sample hike/route without account
writes or sharing to another app. The signed build-199 baseline was restored
after debug tests before checking the 199 → 200 upgrade. No physical-phone
log bundle was supplied.
