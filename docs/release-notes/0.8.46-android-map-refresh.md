# HikeJournal Android 0.8.46 — Main map initial focus

## Release scope

Android only. Canonical `VERSION` and Android `versionName` remain `0.8.46`;
Android `versionCode` advances from `179` to `180`.

## Android

- Keep map loading active while cached map data is read, so an old cache cannot
  mark the map as fitted before the current photo summary arrives.
- Apply the summary's photo bounds once they are available, even if the map
  already fitted a cached snapshot. The resulting camera-idle event requests
  markers for the focused area; settled pan and zoom changes continue to load
  their own viewport.

## iOS

No functional changes. iOS marketing version and build number are unchanged;
no iOS build or archive was made.

## API

No functional changes. The API version and contracts are unchanged; no API
deployment is required.

## Web

No functional changes. No Web artifacts were built or shipped.

## Shared code

No functional changes.

## Debug-log triage

The Android 15 emulator's targeted `AndroidRuntime` log check was empty after
upgrade; no physical-device log bundle was supplied. A read-only production
database smoke check confirmed the viewport RPC returned matches and overview
clusters across the tested photo bounds. No backend row cap or empty-result
condition was observed.

## Validation

- Android debug and release unit tests: 180 passed in each variant.
- `./build_android.command personal`: passed, including signed canonical
  APK/AAB packaging and promotion.
- APK release verifier: passed with no findings for package
  `com.hikejournal.app`, version name `0.8.46`, version code `180`, and the
  expected permanent signer.
- Strict AAB signature verification and permanent signer identity: passed.
- Signing-lineage upgrade: Android 15 accepted the in-place update from version
  code `179` to `180`; the app launched without an `AndroidRuntime` error.
- `:app:lintRelease`: passed.
- `git diff --check`: passed.

## Deployment and artifacts

The signed Android APK is attached to the platform-qualified GitHub release
`android-v0.8.46-map-refresh`. The signed AAB was built and verified but is not
attached. No server deployment is needed because the API is unchanged.
