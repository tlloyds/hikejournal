# HikeJournal 0.8.41

## Release scope

Android + iOS + API. Place Profiles now show the shared satellite map style
with every saved GPS route recorded at that place.

## Place route maps

- Added place-scoped route data to the Place Profile API, keyed by the hike ID
  already used by visit history and location tags.
- Added satellite route snapshots to Android and iOS Place Profiles, reusing the
  journal route styling and overlaying all saved routes at the place.
- Kept a route-sketch fallback for offline or unavailable map tiles, and kept
  coordinate-only place maps for places without a recorded route.
