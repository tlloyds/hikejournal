# HikeJournal Android 0.8.43 — Fast route replay

## Release scope

Android only. Saved hike routes can now be replayed quickly from the Journal.
`VERSION` and Android `versionName` remain `0.8.43`; Android `versionCode`
increases from `169` to `170`. iOS, API, Web, and shared code have no
functional changes.

## Android

- Added a full-screen satellite route replay with a moving position marker,
  play/pause, replay, and a progress scrubber.
- The full saved route stays visible as context while the traveled line is
  revealed over 24 seconds, independent of hike duration.
- Separate recording and imported TCX route segments stay disconnected during
  replay; the route is not extended across a pause or track break.
- Existing live tracking, TCX import, route storage, and the normal Journal map
  preview remain unchanged.

## iOS, API, Web, and shared code

- No functional changes.
- No iOS archive or Web/API artifacts were built or shipped. iOS version and
  build metadata are unchanged.
- No API deployment is required because API code and contracts are unchanged.

## Debug-log triage

No new Android debug logging was added. The Android 15 emulator launch
produced no `AndroidRuntime` errors. No physical-device runtime log bundle was
available for separate triage.

## Validation

- `:app:testDebugUnitTest` and `:app:testReleaseUnitTest`: passed, 172 tests
  across 49 suites in each variant.
- `./build_android.command personal`: passed, including release lint and
  signed APK/AAB packaging.
- APK release verifier: passed with no findings; package
  `com.hikejournal.app`, version name `0.8.43`, version code `170`, expected
  permanent signer.
- Strict AAB signature verification and signer identity: passed as part of the
  personal release build.
- Signing lineage: `apksigner` verified the configured prior signer for API
  26–27 and the permanent signer for API 28+. An Android 15 emulator upgraded
  from installed version code 166 to 170 and launched `MainActivity` without
  an Android runtime exception.
- `git diff --check`: passed.
