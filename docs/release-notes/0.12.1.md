# HikeJournal 0.12.1 · Automatic references for newly confirmed plants

Release scope is API. GitHub tag `v0.12.1`.

## API

- A newly confirmed plant ID can automatically pick up available food and ethnobotany references. Lookups also run when the Field Guide refreshes or a species detail opens. Recent confirmations get priority.
- Automatic matching checks the active World Checklist of Food Plants release and a pinned candidate catalog of 43,707 names from Kew's World Checklist of Useful Plant Species and the USDA Duke archive. Cross-references retain their source and locator. They can appear independently of food and toxicity findings.
- The Supabase migration records completed and retryable lookups by shared taxon ID, preserves existing review decisions, and expires stale assessments. Interrupted work can retry during normal journal use.
- The shared API version advances from **0.12.0** to **0.12.1**. The installed Android release can use the update. The [reference documentation](../EDIBILITY_REFERENCE.md) describes matching, updates, and source renewal.
