# HikeJournal Android 0.8.43 — Single-photo sharing

## Release scope

Android only. The Android photo viewer now shares one saved photo from either the gallery or a hike through the Android Sharesheet. `VERSION` and Android `versionName` remain `0.8.43`; Android `versionCode` increases from `168` to `169`. No iOS, API, Web, or shared functional changes are included.

## Android

- Added a Share action to the photo viewer used by gallery photos and photos opened from a hike or its map.
- The app prepares the selected original image in its private share cache and grants the receiving app read access through a `FileProvider` URI.
- Opens the native Android Sharesheet with an `image/*` attachment and the photo note when available. Videos are excluded from this photo action.
- The GPS-safe phone-original photo browser and its permissions remain unchanged.

## iOS, API, Web, and shared code

- No functional changes.
- No iOS archive or Web/API artifacts were built or shipped. iOS version and build metadata are unchanged.
- No API deployment is required because API code and contracts are unchanged.

## Debug-log triage

No new Android debug logging was added. The release build emitted no new compiler warnings. No physical-device runtime log bundle was available for separate triage.
