# HikeJournal 0.8.30

## iOS

- Discover now provides an explicit Field Quest target picker below the nearby
  species list.
- Tap `Select` beside any species to choose 1–10 targets; selected targets are
  numbered, highlighted, and persisted when the quest is saved.
- Species rows retain their detail view, while the save action explains when a
  saved area or target selection is still required.
- Stabilized the Field Guide search placement as a persistent navigation-bar
  drawer to avoid transient SwiftUI search-bar constraint churn.

## Android

- No functional Android changes were made.
- Version metadata advanced to `versionName` 0.8.30 and `versionCode` 151.

## Web

- No web behavior changed in this release.

## API

- No endpoint or schema changes were required.
- iOS uses the existing quest creation endpoint followed by the existing focus
  target update contract (`focus_taxon_ids`), matching Android behavior.

## Debug-log triage

- The `nw_*` connection messages, gesture timeouts, dictation messages, and
  Core Location main-thread advisory are simulator or Apple framework
  diagnostics; they do not indicate a Field Quest failure.
- MapLibre's missing `default.csv` / `satellite.styl` messages come from its
  packaged framework resources and are not emitted by HikeJournal code; maps
  continue to load from the configured style.
- The actionable SwiftUI search-bar layout warning was addressed by pinning the
  search UI to the navigation-bar drawer placement.

## Verification

- Full iOS Debug build and XCTest suite passed on the iPhone 14 Pro Max
  simulator.
- HikeJournalDomain Field Quest selection tests passed.
- Android personal APK/AAB built and passed release verification.
