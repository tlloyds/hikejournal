# HikeJournal 0.8.49 · Android build 203

Scope is Android only. Release tag `android-v0.8.49-species-comparison`.

## Android

- In **Species → Collection**, tap **Compare**, select two species, then tap **Compare species**. Selections carry across searches and filters. Return to the list to swap either species.
- The comparison aligns cover photos, common and scientific names, local status, encounter counts, and available Wikipedia descriptions. If the full-size photo is unavailable, HikeJournal tries the thumbnail.
- Android `versionCode` increased from **202** to **203**. The Android version name and shared `VERSION` stay at **0.8.49**.
