# HikeJournal 0.8.28

## iOS

- Hike media details now page through every photo in the selected hike. Swipe
  left or right to move between photos while keeping the selected photo's
  caption, species, location, and actions in sync.
- Discover labels the date control `Hike date` and restores the species detail
  sheet when a nearby species is tapped. Species details include the existing
  `View sightings` map action.
- Species Review now presents one review card at a time in a swipeable deck,
  with candidate selection, confirm, reject, skip, and remove-from-review
  actions. Rejecting a suggestion keeps the photo queued for another
  recommendation, matching Android behavior.
- Location requests now resume cleanly when cancelled instead of leaking an
  async continuation.

## API

- No API endpoint or schema change is required. The existing discovery,
  nearby-sightings, and species-review contracts remain compatible.
- The mobile API version is automatically `0.8.28` from the canonical
  repository version.

## Web

- No web UI change is required. Shared review and discovery behavior remains
  compatible with the existing Streamlit workflows.

## Verification

- iOS Debug build passed on the installed iPhone 14 Pro Max iOS 26.5 simulator.
- Hosted iOS XCTest suite passed.
- Android personal APK and AAB passed release signing and artifact verification.
- No API or web deployment is required for this client-only compatibility release.
