# HikeJournal Android 0.8.44 — Species Review connectivity recovery

## Release scope

Android only. Species Review now refreshes its cached queue when validated
internet connectivity returns. Canonical `VERSION` and Android `versionName`
remain `0.8.44`; Android `versionCode` advances from `173` to `174`.

## Android

- Detect online state using Android's `INTERNET` and `VALIDATED` network
  capabilities, including validation changes on an existing Wi-Fi or cellular
  connection.
- When a requested Species Review queue transitions from disconnected to
  connected, automatically fetch the queue again so decisions resume without
  leaving the screen.
- Preserve the existing refresh control and cached offline queue.
- Android metadata: `versionName` `0.8.44`, `versionCode` `174`.

The supplied screenshot showed the cached review queue with decisions paused

## Validation

- `:app:testDebugUnitTest` and `:app:testReleaseUnitTest`: passed, 175 tests
  across 49 suites in each variant.
- `./build_android.command personal`: passed for Android `versionCode` `174`;
  release lint and canonical APK/AAB packaging passed.
- Release APK verifier: passed with no findings. Strict AAB signature
  verification, permanent signer identity, and configured signing lineage
  checks passed.
- Android 15 emulator: installed the signed version `173` APK, upgraded it
  in place to version `174`, and launched `MainActivity` without an
  `AndroidRuntime` fatal exception.
- The reconnect transition is covered by unit tests in both build variants.
  The emulator had no authenticated review queue available for an end-to-end
  Species Review interaction.
