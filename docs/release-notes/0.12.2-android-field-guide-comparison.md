# HikeJournal 0.12.2 · Android build 210

Release scope is Android. GitHub tag `android-v0.12.2-field-guide-comparison`.

## Android

- In **Field Guide → Collection → Compare**, select two species. The comparison puts both cover photos, names, local status, available plant evidence, and encounter counts in two aligned columns. On taller screens the names stay visible while you scroll. Open the Wikipedia descriptions when you want more detail.
- **Edibility & uses** presents safety findings first, followed by food-use evidence and traditional uses. A general food-use report is labeled separately from a cited finding about a specific plant part. Conflicting reports stay qualified, and individual findings retain their source links.
- The comparison uses the same current plant evidence as the Field Guide. When a collection entry covers several identifications, each finding stays under its exact scientific name.
- Android `versionCode` advances from **209** to **210**. Android `versionName` and shared `VERSION` remain **0.12.2**.

## Validation

- All 196 Debug and 196 Release unit tests passed. Release lint reported zero errors, 60 warnings, and one hint, matching the prior release.
- All 53 Android 15 emulator tests passed. Two comparison tests also passed at a 320 dp phone width. Coverage includes selection across searches, aligned columns, missing photos, exact-taxon evidence, and pinned names while reading descriptions.
