# HikeJournal 0.8.49 — species count and filter polish

Scope: **Android only**.

## Android

- Reduce the observation count at the right of each Field Guide entry from
  26 sp to 18 sp. Align the thumbnail, species information, and count at the
  top of the entry so the number sits beside the species name, matching the
  supplied reference even when a name wraps onto two lines.
- Use regular-weight text for the selected outing and observation-type filter
  values, including “All hikes” and “All types”. The shared outing filter also
  carries this lighter weight into Publish.
- Keep the existing two-digit minimum count formatting, colors, and filtering
  behavior.
- Android version name remains **0.8.49**. Increment `versionCode` from
  **195** to **196** for this distributed build. Shared `VERSION` is unchanged.
- Tag: `android-v0.8.49-species-count-polish`.

## Debug-log triage

The first instrumentation attempt could not install the debug test app over
an existing permanently signed release. The test runner cleaned up that
installation; the subsequent two-test run passed. The signed build-195 baseline
was then restored before independently checking the signed 195 → 196 upgrade.
This was a test setup/signature mismatch, not an app test failure.

Existing `requestSingleUpdate`/`Locale` deprecations and the existing lint
warnings/hint remain. The SDK 26–27 verifier retains its expected warning about
the newer signature scheme. No production logging was added, and no new
runtime crash was observed. No physical-device log bundle was supplied.
