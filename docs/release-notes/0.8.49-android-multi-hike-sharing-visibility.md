# HikeJournal Android 0.8.49 — Multi-hike share button visibility (build 188)

## Release scope

Android only. This is a visibility correction for the same-day multi-hike share
control. Canonical `VERSION` and Android `versionName` remain **0.8.49**;
Android `versionCode` advances from **187 to 188**.

## Android

- The **Combine outings from this day** action in the existing share preview
  now uses an amber outline and explicit amber icon and text colors. Its prior
  text-button tint blended into the dark-green background, making the action
  effectively invisible even when it was present.
- The button remains in the space below the Trail Keepsake choices and above
  the keepsake preview. Its same-day eligibility and navigation are unchanged.
- Android metadata: `versionName` **0.8.49**, `versionCode` **188**.
