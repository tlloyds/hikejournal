# HikeJournal 0.9.0

Android build 204. GitHub release tag `v0.9.0`.

## Android

- The Field Guide adds **Edibility & Ethnobotany** with cited human food-use records, separate toxicity information, and source attribution. Confirmed plant tags can open the reference from private photo views. Photo indicators default off and can be enabled in Settings.
- The **Documented food uses** filter preserves warning labels. Cached references expire and clear when the app learns that a photo ID or the active dataset has changed.
- The shared version and Android version name advance from **0.8.49** to **0.9.0**. Android `versionCode` advances from **203** to **204**.
- Reference data is live on the production API. Refresh the Field Guide in build 204 to load it.

## API and shared code

The repository adds the pinned World Checklist of Food Plants importer, exact-taxon iNaturalist matching, a resumable backfill, and nullable reference fields in the mobile API. Production now serves API 0.9.0 with `EDIBILITY_ENABLED=true`. The Supabase migration, WCFP v2 import, and confirmed-taxon audit passed before activation. [Source audit and staging runbook](https://github.com/tlloyds/hikejournal/blob/main/docs/EDIBILITY_REFERENCE.md)

## iOS

No functional changes. The generated marketing version follows the shared `VERSION` file. The iOS build number is unchanged.

## Web

No functional changes.

## Verification

- Python passed 586 tests. Android passed 191 Debug and 191 Release unit tests. Feature validation also passed 44 Android 15 emulator tests. Release lint reported zero errors, 60 warnings, and one hint.
- `./build_android.command personal` produced verified signed APK and AAB artifacts. The APK release verifier reported no findings. Strict AAB verification matched the permanent signer.
- APK verification passed for API 26–27 and 28–36. The signing lineage and capabilities matched build 203. An Android 15 in-place upgrade preserved the app ID and original install time. The app launched and resumed successfully.
- The generated iOS version matched `VERSION` in the config validator. `git diff --check` passed.

## Debug-log triage

No crash was observed after the signed upgrade launched. The API 26–27 signature check emitted the existing warning about an unrecognized newer signature scheme. The test runners reported the existing Starlette, Android location, and test locale deprecations.
