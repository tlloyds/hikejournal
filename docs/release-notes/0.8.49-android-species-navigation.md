# HikeJournal 0.8.49 — cleaner species navigation and Hikes shortcuts

Scope: **Android only**.

## Android

- Remove the tall dark alphabet rail from the Field Guide and restore the
  full width of every species row. Observation counts and names no longer
  reserve a gutter for that overlay.
- Replace the rail with a small “Jump to…” action above long collections.
  Letters appear in a light bottom sheet only when requested, with 48 dp tap
  targets. Selecting a letter dismisses the sheet and jumps to that section.
- Jump choices follow the current sort and filtered list: common/scientific
  name initials for name sorts, list positions for recent/encounter sorts.
  Small collections keep the simple Species Index label.
- Keep “Plan my next hike” and “View my trail medals” on one line. Both
  shortcuts share a measured text size fitted to the available width,
  preserving the full labels and the existing 58 dp touch targets.
- Android version name stays **0.8.49**. Increment `versionCode` from **196**
  to **197**. Shared `VERSION` remains unchanged.
- Platform-qualified tag: `android-v0.8.49-species-navigation`.

## iOS

No functional changes. No iOS build/archive or version/build changes.

## Web

No functional changes. No website deployment.
