# HikeJournal 0.8.34 Android GPS-originals release

## Release scope

Android only. The shared semantic version remains 0.8.34 and Android
`versionCode` advances from 156 to 157. iOS, API, and Web have no functional
changes and no artifacts are shipped for them.

## Android changes

- Restored HikeJournal's full local-media browser for photo and video
  attachments.
- Restored the phone-original path required to retain EXIF GPS metadata for
  photo maps and coordinate-backed iNaturalist publishing.
- Restored Android media-library permissions, including the Android 14
  selected-media declaration and legacy Android 12-and-earlier access.
- Added the detailed Play photo/video permission justification at
  `docs/play/PHOTO_VIDEO_PERMISSION_JUSTIFICATION.md`.

## Release validation

- Python test suite: 526 passed.
- Android debug unit tests and Kotlin compilation: passed.
- Signed release APK/AAB: verified by `build_android.command personal`.
- Release artifacts: `dist/HikeJournal-v0.8.34.apk` and
  `dist/HikeJournal-v0.8.34.aab`.
- Android release uses version code 157 and the configured permanent signing
  identity; strict signature and signing-lineage verification passed.
