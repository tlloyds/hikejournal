# HikeJournal 0.12.0 · Edible Field Guide filter and more plant references

Release scope is Android and API. Android build 208. GitHub tag `v0.12.0`.

## Android

- Restored the **Edible** filter in the Field Guide. It includes confirmed plants with documented food use. Entries with conditional or checklist-only evidence still show those qualifications.
- Species with reviewed edible parts display **Edible**. When a different part is toxic, a separate **Toxic parts** label appears on the same row, and the species stays visible in the filtered list. The detail page shows the evidence beside each named plant part.
- **Sources & notes** now includes additional reference links, short summaries, and publication or archive locators. A species can show **Edibility unknown** and still link to historical or botanical records.
- Android `versionName` advances from **0.11.0** to **0.12.0**. Android `versionCode` advances from **207** to **208**.

## API and reference data

- Indexed 256 Kew and USDA cross-references across 196 exact species. The index includes 176 Kew checklist entries and 1,388 cited rows from Dr. Duke’s USDA archive grouped across 80 species. The importer verifies the frozen downloads and checks the active iNaturalist name, rank, family and identity. This release uses the existing reference schema and feature flag.
- Added reviewed references from USDA NRCS and GRIN, the European Medicines Agency, UF/IFAS and Florida Poison Control. The reviewed catalog now includes 58 plant-part findings, 14 traditional-use records, and six supplemental citations across 50 exact species. Examples include the distinction between cattail pollen and young flower stalks, the historic use of Spanish moss in dollmaking, and corroborating references for pokeweed toxicity and Brazilian pepper contact hazards.
- The API includes linked `cross_references` alongside the existing food and traditional-use data. A broad category or historical-use index entry is a research lead. Food and toxicity labels depend on qualifying food and hazard evidence.
- A read-only check using the 417-entry Field Guide audit and the live reference database found 216 entries with an exact reference, 196 with supplemental citations, 136 with documented food use, and 41 with part-level evidence. Newly confirmed records automatically pick up references for their exact indexed taxa. Expanding the supplemental index to new taxa and renewing WCFP matches still require import and backfill runs. See the [source and coverage audit](../EDIBILITY_REFERENCE.md).
- The shared API version advances from **0.11.0** to **0.12.0**.
