# HikeJournal 0.8.39

## Release scope

Android + iOS. The map now supports independent photo and route visibility,
and selected-trail route sharing uses stricter geometry matching. API and Web
have no functional changes and no artifacts are shipped for them.

## Android

- Added a Map display control with independent Photos and Routes toggles on
  the sightings map and per-hike map. Both, photos only, and routes only are
  supported.
- Reworked selected-trail route sharing to compare actual route geometry,
  use a tighter 24 m centerline tolerance, and require stronger direction
  agreement. This prevents nearby parallel paths from being colored as shared.
- Android version metadata: `versionName` 0.8.39, `versionCode` 162.

## iOS

- Added the same Photos and Routes display controls to the native map surface.
- Added shared-route highlighting with the same stricter centerline and
  direction matching used by Android.
- `ios/Config/Version.xcconfig` is synchronized to canonical version 0.8.39.
- iOS `CURRENT_PROJECT_VERSION` advanced from 14 to 15.

## API and Web

- No functional changes.
