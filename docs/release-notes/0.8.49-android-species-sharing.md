# HikeJournal 0.8.49 — Species photo sharing

Scope: **Android only**.

## Android

- Add a Share button to each Field Guide species detail page. Open a species
  such as Pine Lily, tap Share, and choose its encounter photos across outings.
- Select photos in the order they should appear, with numbered selections,
  Select all/Clear, and the same 20-image carousel limit as hike sharing.
- Choose **Keepsake first**, **Keepsake last**, or **No keepsake**. Keepsakes
  allow 19 selected photos; photos-only sharing allows 20. Adding a keepsake
  retains the first 19 selections, and photos-only sharing requires a photo.
- Introduce a branded **Field Guide Keepsake** with the first selected photo,
  common/scientific names, and encounter/outing totals. With no photo selected,
  the keepsake uses an encounter photo or the species cover when available.
  The preview and 1080 × 1350 export use the same renderer and bundled fonts.
- Share original photo files through Android's Sharesheet. Exclude videos,
  missing URLs, duplicate encounters, and IDs outside the current species.
  Partial download failures show a notice; empty photos-only exports fail with
  a retry message. Separate share files preserve previous open attachments.
- Reuse the hike-sharing attachment handling, image ordering, photo selection
  tile, and keepsake texture. The GPS-safe phone-original upload picker and
  photo/video permissions are unchanged.
- Android version name remains **0.8.49**. Increment `versionCode` from **200**
  to **201**. Shared `VERSION` remains unchanged.
- Platform-qualified tag: `android-v0.8.49-species-sharing`.

## Debug-log triage

Earlier checks exposed a preview/copy overlap and Android 15 dialog sizing around system bars; both were corrected before release. The gallery is clipped to its own scroll region. UI tests were adjusted to locate lazy photo rows inside the dialog, and native screenshots wait for window rendering. The initial debug-test installation conflicted with the installed release signer; the emulator state was saved/restored and the verified build-200 APK was reinstalled before the upgrade check. Final checks passed. The 59 existing lint warnings, one new suggestion to use the Canvas KTX convenience function, and the expected SDK 26–27 newer-signature warning remain. No production logging was added, no account writes or external shares were performed during testing, and no physical-phone log bundle was supplied.
