# HikeJournal Android 0.8.49 — Navigation refinement (build 191)

**Release scope: Android only.** This release restores the designer's main
Hikes navigation layout while keeping every existing destination and action
available.

## Android

- The Hikes screen bottom navigation shows Hikes, Species, Review, and Map.
  Publish is hidden there and the existing add action appears as a plus button
  to the right of the navigation bar.
- Publish becomes visible in the bottom navigation while browsing Species or
  Review, and remains visible when Publish itself is selected.
- The plus button uses the existing add-hike / everyday-sighting flow. No
  journal data, publishing behavior, or other action changed.
- `VERSION` and Android `versionName` remain **0.8.49**. Android
  `versionCode` is **191**, incremented from **190** for this distributed
  build.
