# HikeJournal Android 0.8.49 — Typography and Review polish (build 195)

**Release scope: Android only.** This follow-up refines text hierarchy and brand
colors after the design-alignment release and moves Batch ID out of the Review
header.

## Android changes

### Font provenance

- Rechecked the supplied Illustrator file. Its metadata explicitly identifies
  `Quicksand-Light` and `Quicksand-VariableFont_wght.ttf`. The app uses real
  Quicksand instances for body copy, labels, and branded headers.
- Clarified the artwork notes: the file does not identify every outlined or
  rasterized typeface. Cormorant Garamond was retained from the existing app
  for editorial serif titles; it was not positively identified from Illustrator
  metadata. No font assets were replaced in this release.

### Hikes and Field Guide

- Reduced Current outings from 20 sp to 15 sp and Archives from 17 sp to 15 sp,
  using regular body weight for the quieter navigation hierarchy in the design.
- Changed featured and journal hike titles from semibold to regular serif
  weight while preserving their sizes. List/comparison hike titles and Everyday
  Sightings also use regular weight.
- Kept the improved featured-date badge size and bold label, with solid white
  text on the existing orange background.
- Matched list hike dates, Various dates, and other hike-date labels to the
  add button's orange, `#D17D42`.
- Reduced Field Guide list species names from 20 sp to 17 sp, scientific names
  from 15 sp to 14 sp, and encounter/outing metadata to a lighter 13 sp style.
- Matched Filter by outing, Observation type, and encounter/outing metadata
  to the same orange token.

### Species Review

- Removed the small Batch ID action from the header, leaving its refresh
  action and the existing branded title.
- Added a full-width Batch ID button below Identify this sighting. It appears
  on an observation awaiting suggestions only when more than one observation
  in the queue needs ID.
- Suggested observations and queues with only one waiting observation do not
  show the batch action. Sync, loading, offline, and active-operation checks
  prevent an unavailable batch request.
- The button opens the existing batch planner, or starts the existing
  iNaturalist connection flow when required. Existing batch progress/resume
  and submission behavior are preserved.

### Publish and Map

- Matched the Publish outing-filter label and hike title to `#D17D42`.
- Changed Ready to post and other orange status badges to solid white text.
  Featured hike dates use the same shared badge styling.
- Matched the selected map photo's date to the add button's orange.

The existing logos, header textures, bottom navigation proportions, Google
sign-in/setup branding, GPS-safe phone-original browser, media permissions,
and photo GPS handling are preserved.
