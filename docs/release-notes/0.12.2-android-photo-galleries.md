# HikeJournal 0.12.2 · Android build 211

Release scope is Android. GitHub tag `android-v0.12.2-photo-galleries`.

## Android

- Swipe either photo in **Field Guide → Collection → Compare** to browse that species' journal photos. Each gallery keeps its own position and shows a photo counter when more photos are available.
- Each cover remains available while its encounter photos load. If a gallery fails to load, retry it from its own column.
- Shared headings for local status, edibility and safety, journal encounters, and Wikipedia descriptions are centered across both columns.
- Android `versionCode` advances from **210** to **211**. Android `versionName` and shared `VERSION` remain **0.12.2**.

## Validation

- All 196 Debug and 196 Release unit tests passed. Release lint reported zero errors, 60 warnings, and one hint, matching build 210.
- All 54 Android 15 emulator tests passed. Three focused comparison tests also passed at 320 dp. Coverage includes independent swipes, retrying one gallery, keeping the cover during loading, centered headings, and missing photos.
- `./build_android.command personal` produced the signed APK and AAB. The APK passed the release verifier and signature checks for API 26–27 and 28–36. The AAB passed strict signature verification with the expected permanent signer.
- The APK certificate lineage and capabilities matched build 210. An in-place Android 15 upgrade preserved the app ID and original install time, then launched and resumed successfully.
