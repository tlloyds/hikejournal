# HikeJournal 0.8.34 Android photo picker release

## Release scope

Android only. This is a platform-qualified Android release that keeps the
shared semantic version at 0.8.34 and advances Android `versionCode` from 155
to 156. iOS, API, and Web have no functional changes and no artifacts are
shipped for them.

## Android

- Replaced full-library media access with Android's system Photo Picker for
  photo and video attachments.
- Removed broad media-library permissions from the Android manifest.
- Kept the phone-original upload path: selected URIs are retained while the
  upload sheet is open, original bytes are requested when available, and EXIF
  GPS is read before upload.
- The in-app review screen now shows only media selected through the system
  picker.

## Validation

- Managed Android policy tests passed.
- Debug Kotlin compilation passed.
- Release APK/AAB verification, signature identity, and signing-lineage
  checks are required before promotion.
