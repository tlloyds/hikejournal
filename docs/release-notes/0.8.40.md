# HikeJournal 0.8.40

## Release scope

Android + iOS + API/shared. Web has no functional changes and no Web artifact
is shipped.

## Android

- Added a conservative USDA PLANTS fallback for unresolved plant nativity in
  the configured Florida region, while leaving ambiguous or genus-level cases
  as Status unknown.
- Changed ecology status labels in the species collection and species record
  to use stronger color, larger type, and bold weight.
- Brightened and enlarged the encounter/outings counts in the species
  collection and species record.
- Android version metadata: `versionName` 0.8.40, `versionCode` 163.

## iOS

- Added the same higher-contrast, bolder ecology status treatment to the
  species collection and species record hero.
- Brightened and enlarged the encounter/outings counts in the species
  collection.
- Synchronized `ios/Config/Version.xcconfig` to canonical version 0.8.40.
- iOS `CURRENT_PROJECT_VERSION` advanced from 15 to 16.

## API and shared services

- Added USDA PLANTS state-level nativity lookup as a fallback when iNaturalist
  has no place-aware establishment value.
- Unknown current-region ecology snapshots are now eligible for retry, so a
  later backfill or enrichment request can resolve them instead of treating
  `unknown` as permanently complete.
- Corrected the backfill skip condition so only known current-region snapshots
  are skipped.
- Live Florida backfill refreshed 570 canonical taxa and updated 662
  observation snapshots. The canonical distribution after the backfill was
  native 325, non-native 64, and unknown 181; 15 taxa use the USDA fallback.

## Web

- No functional changes.
