# HikeJournal 0.8.36

## Release scope

Android + iOS. The journal-library layout now presents the most recent hike
first, followed by Everyday Sightings, with the remaining hikes below. API and
Web have no functional changes and no artifacts are shipped for them.

## Android

- Moved the large most-recent-hike cover presentation above Everyday Sightings.
- Kept Everyday Sightings as the first thin journal row after the featured hike.
- Formal hikes are ordered by most recent hike date before the featured row is selected.
- Android version metadata: `versionName` 0.8.36, `versionCode` 159.

## iOS

- Ordered the journal list with the most recent formal hike first.
- Pinned Everyday Sightings as the second journal entry when it matches the active scope/search.
- Kept the existing list-row presentation and journal actions unchanged.
- `ios/Config/Version.xcconfig` is synchronized to canonical version 0.8.36.
- iOS `CURRENT_PROJECT_VERSION` advanced from 12 to 13.

## API and Web

- No functional changes.
