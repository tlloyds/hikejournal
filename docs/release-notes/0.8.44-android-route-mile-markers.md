# HikeJournal 0.8.44 — Route replay mile markers

## Release scope

Android plus mobile API version metadata. Route replay now shows elapsed and
total distance and numbers each whole-mile point along the route. Canonical
`VERSION` and Android `versionName` increase from `0.8.43` to `0.8.44`;
Android `versionCode` is `173`.

## Android

- Show live elapsed distance against total route distance during playback.
- Add numbered mile markers along the route. Markers change to the route's
  orange highlight as playback reaches each mile.
- Keep route-distance playback, camera framing, and speed controls intact.
- Set Android `versionName` to `0.8.44` and increment `versionCode` from `172`
  to `173`.

## iOS

- No functional changes. No iOS archive was built or shipped.
- Synchronize `MARKETING_VERSION` to `0.8.44`; `CURRENT_PROJECT_VERSION`
  remains unchanged. No iOS build or archive was made.

## API

- No endpoint, schema, or behavior changes. The mobile API reports canonical
  version `0.8.44` after deployment.

## Web

- No functional changes. No Web artifacts were built or shipped.

## Shared code

- No functional changes.
