# HikeJournal Android 0.8.43 — Route replay controls

## Release scope

Android only. The route replay controls now sit higher above the screen edge and
use stronger contrast. `VERSION` and Android `versionName` remain `0.8.43`;
Android `versionCode` increases from `170` to `171`. iOS, API, Web, and shared
code have no functional changes.

## Android

- Lift the route replay controls clear of the bottom system area so the play
  row remains visible on shorter screens.
- Give the control area a stronger dark backdrop, a high-contrast orange and
  cream scrubber, and a distinct play/pause button.
- Keep the 24-second distance-weighted replay behavior unchanged.

## iOS

- No functional changes.
- No iOS archive was built or shipped. iOS version and build metadata are
  unchanged.

## API

- No functional changes. No API deployment is required because API code and
  contracts are unchanged.

## Web

- No functional changes. No Web artifacts were built or shipped.

## Shared code

- No functional changes.

## Debug-log triage

No new Android debug logging was added. The Android 15 emulator launch produced
no `AndroidRuntime` errors. No physical-device runtime log bundle was available
for separate triage. The emulator profile was at first-run onboarding, so the
route replay screen could not be opened for a route-specific visual check.
