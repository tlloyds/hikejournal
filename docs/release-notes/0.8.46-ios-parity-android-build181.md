# HikeJournal 0.8.46 — iOS parity polish and Android build 181

## Release scope

iOS and Android. This GitHub release packages Android build 181. The iOS app
was built for the local iPhone 17 Pro simulator for hands-on review; no iOS
archive or App Store upload was made. This is not the paid-Plus store launch
candidate: Google Play subscription purchase and server verification remain
unfinished, and the store product records have not been created.

## iOS

- Collect batch celebration image URLs with a deterministic loop, preventing
  lazy reevaluation from consuming the image list before it is displayed.
- Repair the Maps package's malformed GeoJSON test fixture so its test target
  compiles.
- Add a scientific-name Field Guide sort and use the shared parsed-date sorter
  for recent and encounter ordering.
- Add single-photo sharing from journal photo detail. HikeJournal stages the
  selected still image in a protected temporary file, includes its note, and
  reports preparation failures. Videos do not show this action.
- iOS marketing version remains `0.8.46`; App Store build remains `18`.
  Simulator build only; no App Store archive or upload.

## Android

No functional changes. Android `versionName` remains `0.8.46`; `versionCode`
advances from `180` to `181` for this distributed build. The GPS-safe original
photo browser remains wired to the journal.

## API

No functional changes. API semantic version remains `0.8.46`; no API deployment
was made.

## Web

No functional changes; no Web artifacts were built or shipped.

## Shared behavior

No cross-platform API or entitlement changes. Android Play Billing, verified
purchase projection, shared quota enforcement, Apple deletion/revocation,
iOS viewport maps, progressive large-hike loading, durable Review decisions,
and iOS route replay remain open work. See the
[implementation plan](https://github.com/tlloyds/hikejournal/blob/main/docs/roadmaps/IOS_ANDROID_STORE_LAUNCH_PLAN.md)
for the complete launch gates.

## Debug-log triage

No physical-device log bundle was supplied. On the Android 15 emulator, build
181 installed over build 180 with the same permanent signer and launched with
no fatal `AndroidRuntime` entry in the captured log window. The iOS app was
installed and launched in the iPhone 17 Pro simulator.

## Validation

- HikeJournal Domain package: 33 tests passed.
- HikeJournal Maps package: 29 tests passed after repairing the fixture.
- Android Debug unit tests: 180 passed; Release unit tests: 180 passed.
- Android `lintRelease`: passed.
- iOS Debug simulator app build: passed on iPhone 17 Pro / iOS 26.5; app
  installed and launched to the signed-out Account screen.
- `./build_android.command personal`: passed; signed canonical APK/AAB promoted
  only after signer checks.
- Android build 180 to 181 in-place upgrade: passed on Android 15 / API 35;
  upgraded app launched with no `AndroidRuntime` fatal error in the captured
  log window.
- Full hosted iOS XCTest app suite and StoreKit Sandbox purchase lifecycle:
  not run in this candidate.
