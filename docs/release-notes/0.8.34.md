# HikeJournal 0.8.34

## Release scope

Android + iOS. The Field Guide / species collection search now includes the
stored Wikipedia description for each species. The API has no endpoint or
runtime behavior changes, but its reported compatibility version advances with
the canonical `VERSION`. Web has no functional changes and no Web artifact is
shipped.

## Android

- Field Guide collection search now matches common name, scientific name, or
  the stored Wikipedia description, including searches such as `orchid` and
  `sandy`.
- Updated collection search guidance to mention descriptions.
- Android version metadata: `versionName` 0.8.34, `versionCode` 155.

## iOS

- Field Guide collection search now matches common name, scientific name, or
  the stored Wikipedia description, including searches such as `orchid` and
  `sandy`.
- Updated Field Guide search guidance to mention Wikipedia descriptions.
- `ios/Config/Version.xcconfig` is synchronized to canonical version 0.8.34.
- iOS `CURRENT_PROJECT_VERSION` advanced from 10 to 11.

## API

- No API endpoint, schema, or runtime behavior changed.
- The mobile API continues to derive its health and compatibility version from
  `VERSION`; this release reports 0.8.34 after the main-branch deployment.

## Web

- No functional Web or Streamlit changes.

## Diagnosis and debug-log triage

- Search is evaluated locally against the already-loaded Wikipedia summary, so
  typing in the collection does not add network lookups.
- No new production log bundle or physical-device log was available for this
  feature.
