# HikeJournal v0.12.3

Release scope is Android and the mobile API.

## Android

- Use **Add photos & videos** to select both in the same journal batch. Phone Originals browses local albums with embedded GPS access. **Browse files** also accepts both photos and videos.
- Videos can be up to 250 MiB each. The photo limit remains 30 MiB. Video-only selections can be saved directly when GPS is missing.
- Android `versionCode` advances from 211 to 212 and `versionName` advances from 0.12.2 to 0.12.3.

## Mobile API and shared code

- Videos over 30 MiB upload directly to private storage. The API verifies the stored size and media type before creating the journal record. Retrying after an interrupted confirmation reuses the uploaded video and its journal ID.
- The shared `VERSION` advances to 0.12.3. The existing multipart upload endpoint is compatible with earlier clients.

## iOS

No functional changes.

## Web

No functional changes.

## Validation

- All 196 Debug and 196 Release Android unit tests passed. The Android 15 emulator passed all 55 tests, including selecting and queuing a photo and a 35 MiB video together. The same picker test passed at 320 dp. Release lint reported zero errors, 60 warnings, and one hint.
- The Python suite passed 598 tests with one skip. Upload tests covered the 250 MiB boundary, confirmation and retry, GPS metadata, and account isolation.
- Private object storage accepted and verified a 262,144,000-byte video through the signed upload path. The test object was removed.
- The signed APK passed verification for Android API 26–27 and 28–36. The AAB passed strict signature verification with the expected permanent signer. The Android 15 upgrade from build 211 to 212 preserved the app ID and original install time and launched successfully.
- Cloud Run reported version 0.12.3 with all readiness checks passing. An unauthenticated request to the new video upload route returned HTTP 401. ## Debug-log triage

The Android picker fixture was corrected to publish files to MediaStore before opening the picker. The emulator suite and signed upgrade launch recorded no crashes. Existing warnings cover a deprecated Android location API, the newer APK signature scheme on API 26–27, and the Starlette and AnyIO deprecation.
