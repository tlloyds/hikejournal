# HikeJournal Android 0.8.49 — Photo viewer zoom (build 189)

## Release scope

Android only. Android's journal photo viewer and its full-screen photo viewer
now support zoom. Canonical `VERSION` and Android `versionName` remain
**0.8.49**; Android `versionCode` advances from **188 to 189**. The release tag
is `android-v0.8.49-photo-viewer-zoom`.

## Android

- Pinch to zoom photos from 1× to 5×. Double-tap toggles between the fitted
  image and a 2.5× view. Drag to inspect a zoomed image; panning is clipped and
  bounded by the viewer. Moving to another photo resets its zoom.
- The in-place journal photo viewer and the separate full-screen viewer use
  the same zoomable image component. Videos keep their existing playback and
  full-screen controls.
- The viewer continues to load images through its existing Coil `AsyncImage`
  request. Zoom uses a clipped Compose graphics-layer transform, so it does not
  request a larger image or create a second decoded bitmap. The 5× ceiling
  limits the magnification range.
- Android metadata: `versionName` **0.8.49**, `versionCode` **189** (previously
  **188**). `VERSION` is unchanged because this Android-only release does not
  change the shared API semantic version.
