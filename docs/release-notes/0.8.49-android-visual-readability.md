# HikeJournal Android 0.8.49 — Readability and navigation polish (build 192)

**Release scope: Android only.** This visual refinement follows the original
Hikes, Field Guide, Species Review, Publish, and Trail Medals artboards. App
actions, data, and navigation destinations remain unchanged.

## Android

- The featured Hike date now uses a bold white label on a darker orange tag;
  the Cormorant title and supporting photo/location details have clearer
  separation. Secondary outing rows use a more readable date/title/metadata
  hierarchy and no longer repeat the photo count at the row edge.
- The Hikes bottom bar is a fully rounded capsule with the circular orange
  plus beside it. The plus still opens the same add flow. Other destinations
  retain their full-width navigation bar.
- Every Material typography role now uses the bundled Cormorant Garamond or
  Source Sans 3 family. Small labels, counters, section summaries, and status
  text have consistent sizing and weight instead of platform-default fonts.
- Field Guide species rows emphasize common names, orange encounter counts,
  italic scientific names, and readable status copy. Review and Publish have
  stronger queue summaries and photo-state labels; Trail Medals has clearer
  progress and next-medal emphasis.
- Android `versionName` remains **0.8.49**. `versionCode` is **192**,
  incremented from **191** for this distributed build. `VERSION` was not
  changed.

## iOS
