# HikeJournal 0.8.43

## Release scope

Android + API version metadata. This release fixes Field Guide search and
collection filtering on Android. The API reports the new canonical version;
there are no API behavior changes. iOS and Web have no functional changes and
no artifacts are shipped for them.

## Android

- Fixed Field Guide collection search so the displayed species list updates
  immediately while typing.
- Fixed outing, observation-type, and sort controls so each change updates the
  same collection state that drives the list, including when the screen is
  recomposed by Android navigation or data refreshes.
- Kept search matching common names, scientific names, and stored Wikipedia
  descriptions.
- Made observation-type matching stable regardless of the device's default
  locale.
- Android version metadata: `versionName` 0.8.43, `versionCode` 167.

## iOS

- No functional changes.
- `ios/Config/Version.xcconfig` was synchronized to canonical version 0.8.43;
  `CURRENT_PROJECT_VERSION` remains 18. No iOS build, archive, or upload was
  made.

## API

- No endpoint, schema, or runtime behavior changed.
- The mobile API continues to derive its compatibility version from `VERSION`,
  which now reports 0.8.43 after deployment.

## Web

- No functional Web or Streamlit changes.

## Diagnosis and debug-log triage

- The Field Guide controls kept a second local copy of the collection
  preferences while the parent navigation state also owned those values. The
  screen could therefore retain stale search/filter state after a parent
  recomposition. The controls now use the hoisted preferences as their single
  source of truth.
- No production log bundle or physical Android device log was available for
  this fix. Android compiler warnings remained limited to the existing
  deprecated pre-Android-R location API path.

## Validation

- `:app:testDebugUnitTest`: passed (167 tests across 48 test suites).

- Release APK verifier, strict AAB JAR signature verification, permanent
