# HikeJournal Android 0.8.49 — Photo recommendation confidence (build 186)

## Release scope

Android only. Single-photo species recommendations now display confidence
beside each suggested species, matching the existing Species Review display.
Canonical `VERSION` and Android `versionName` remain **0.8.49**; Android
`versionCode` advances from **185 to 186**.

## Android

- After requesting an iNaturalist recommendation from an individual journal
  photo, the “Choose the best match” dialog displays a percentage beneath each
  candidate's species names, including alternative candidates.
- Reuse `reviewConfidenceLabel`, the formatter already used by Species Review.
  For example, either `0.979455` or `97.9455` displays as **98% confidence**.
  Missing or non-finite scores are omitted using the existing policy.
- The cause was a missing confidence text element in `DirectPhotoReviewDialog`;
  the recommendation model and parser already supplied the confidence value.
- Android metadata: `versionName` **0.8.49**, `versionCode` **186**.

## iOS

**No functional changes.** Source review confirmed that the individual-photo
