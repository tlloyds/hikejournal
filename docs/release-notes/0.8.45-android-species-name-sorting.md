# HikeJournal Android 0.8.45 — Species name sorting

## Release scope

Android only. The Species tab can now sort the collection by either common or
scientific name. Canonical `VERSION` and Android `versionName` remain `0.8.45`;
Android `versionCode` advances from `176` to `177`.

## Android

- Name the existing A–Z option “Common name” and add “Scientific name” as a
  second A–Z sort choice.
- Sort scientific names case-insensitively, using common name and record key as
  deterministic tie-breaks.
- Keep encounter-count and most-recent sorting behavior unchanged.
- Android metadata: `versionName` `0.8.45`, `versionCode` `177`.

## iOS
