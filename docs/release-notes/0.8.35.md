# HikeJournal 0.8.35

## Release scope

Android + iOS + API. Journal photo viewers now allow an existing species ID to
be replaced with a Field Guide species or a manually entered name, or removed
entirely. The change is available offline on both mobile platforms and syncs
through the mobile API. Web has no functional changes and no Web artifact is
shipped.

## Android

- Added Edit species ID to the journal photo viewer.
- Users can choose a species from the Field Guide or enter a common and/or
  scientific name manually.
- Added removal of the primary species ID without deleting the photo.
- Species ID changes and removals are durable offline operations and update the
  photo viewer immediately.
- Android version metadata: `versionName` 0.8.35, `versionCode` 158.

## iOS

- Added Edit species ID to the journal photo viewer.
- Users can choose a species from the Field Guide or enter a common and/or
  scientific name manually.
- Added removal of the primary species ID without deleting the photo.
- Species ID changes and removals are durable offline operations and update the
  photo viewer immediately.
- `ios/Config/Version.xcconfig` is synchronized to canonical version 0.8.35.
- iOS `CURRENT_PROJECT_VERSION` advanced from 11 to 12.

## API

- Extended `PUT /v1/photos/{photo_id}/species` with `action: set|remove`.
- Existing assignments can now be updated in place, preserving the observation
  record and identification history.
- Manual names are stored as user-confirmed overrides; removal deletes only the
  primary observation for that photo.
- The mobile API reports compatibility version 0.8.35 after deployment.

## Web

- No functional Web or Streamlit changes.

## Diagnosis and debug-log triage

- No new production log bundle or physical-device log was available for this
  feature.
- Offline changes remain in the existing durable mobile sync queues until the
  API acknowledges them.
