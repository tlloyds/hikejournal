# HikeJournal 0.8.38

## Release scope

Android + iOS + API. Species records now carry a place-aware ecological
status alongside identification confidence.

## Ecology status

- Added regional `Native here`, `Non-native here`, `Invasive here`, and
  `Status unknown` values sourced from iNaturalist establishment means.
- Kept ecological status separate from identification confidence; an
  introduced species is not labeled invasive unless the source explicitly
  reports that status.
- Added canonical `taxon_ecology_statuses` storage, an additive migration,
  configurable iNaturalist place/region settings, and an idempotent backfill
  command for existing observations.
- Added ecology labels to species-library rows, species details, and review
  candidates on Android and iOS.
